# CampusTrack: Student Academic Management System

A Java-based system for managing student academic records, course enrollment, grades, and performance tracking.

## Project Structure

```
CampusTrack/
├── output/         # Generated reports and output files
├── requirement/    # Project requirements
├── sol/            # Solution documents
├── src/            # Java source code
└── READ.md         # Project documentation
```

## Features

- Student registration and profile management
- Course enrollment and credit tracking
- Grade entry and GPA calculation
- Academic performance reports

## Getting Started

1. Navigate to the `src/` folder.
2. Compile and run `Main.java` using:
   ```
   javac Main.java
   java Main
   ```
